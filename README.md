# WELCOME CSC-117 LEARNERS! 🚀

Hello! If you are learning Python programming, you are in the right place. This workspace contains five Python projects designed to help you learn the possibilities of programs involving real-world datasets that YOU can create!

Each project is located in its own folder and includes a Python script (`.py`) and real-world data (usually a `.csv` file).

## The Projects

### 1. ☕ Coffee Shop Inventory (`coffee/`)
Manage a coffee shop's stock!
- **What it does:** Reads an inventory file (this is a sample inventory - I made it up to keep it simple), calculates the total value of your stock, and alerts you if you are running low.
- **Key Skills:** Reading files, doing math with Python, and formatting text.

### 2. 🎬 Streaming Service Analyzer (`streaming_tv/`)
Analyze movies and TV shows from Netflix, Hulu, and Amazon Prime.
- **What it does:** Asks you to pick a platform and tells you about their most popular genres, countries of origin, and content ratings.
- **Key Skills:** User input, working with large datasets, and counting statistics.

### 3. 💸 Student Software Deals (`student_software/`)
Find the best discounts for students. Amazing, right?!
- **What it does:** Scans a list of software prices to find free tools and massive discounts available to students.
- **Key Skills:** Data cleaning (turning text into numbers) and filtering lists.

### 4. 🚢 Titanic Survival Analysis (`titanic/`)
Investigate history's most famous shipwreck.
- **What it does:** Looks at the passenger list to see if "women and children first" was actually true and how ticket price affected survival.
- **Key Skills:** Analyzing social data, calculating percentages, and grouping data.

### 5. ✂️ Rock Paper Scissors Tournament (`collab_rps/`)
Code your own game bot!
- **What it does:** Runs a tournament between different computer strategies to see who is the ultimate Rock Paper Scissors champion.
- **Key Skills:** Writing functions, game logic, and importing code from other files.

## How to Start
1. Open a folder (like `coffee/`).
2. Read the `.md` file inside for specific details.
3. Run the python script (the `.py` file) to see it in action!

Happy Coding! 🐍
